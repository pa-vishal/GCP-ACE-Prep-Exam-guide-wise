Shared VPC + Private Services Access (PSA)

Hub-and-Spoke Architecture

In this setup, prj-xyz-psa-dev is a service project, just like your Cloud Run application project. Neither of these projects owns the VPC.

Instead, a dedicated Host Project owns the Shared VPC network. Both service projects attach to this host to securely communicate over internal IPs.

The "psa" project name stands for Private Services Access. PSA creates a private VPC peering connection to the Google-managed service project where Cloud SQL actually runs.

Key takeaway:
This is a classic hub-and-spoke model. The Host Project is the hub (network + security). Service projects are spokes that deploy workloads. Cloud SQL lives outside your projects but is reachable privately using PSA.
