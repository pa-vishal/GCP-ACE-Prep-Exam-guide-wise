BigQuery — ACE Mental Model (One Page)

🧠 Core Truth (anchor this)

BigQuery is a serverless analytics engine where cost is driven by how much data you scan.
You optimize by designing tables — not by tuning servers.

If you remember that sentence, you’re already ahead.

1️⃣ When to Use BigQuery (vs Cloud SQL)

Requirement Choose
Analytics, reporting BigQuery
Large scans, aggregates BigQuery
Transactions, updates Cloud SQL

🧠 Rule: OLAP → BigQuery. OLTP → Cloud SQL.

2️⃣ Data Organization (MOST important for cost)

Datasets

  • Fixed location (regional / multi-region)
  • Tables inherit location
  • Cannot be changed later

🧠 Choose location carefully.

Tables

  • Partitioning

    • Reduce data scanned
    • Most commonly by date/timestamp

  • Clustering

    • Speed filtering within partitions

🧠 Rule:

Partition first, cluster second.

3️⃣ Data Ingestion

Method Use Case
Batch load Large historical data
Streaming Near-real-time
Load from GCS Most common

🧠 GCS is the front door to BigQuery.

4️⃣ Query Cost Model (ACE GOLD)

BigQuery charges for:

  • Bytes scanned

Not charged by:

  • Rows returned
  • CPU time

🧠 Golden rule:

“Small result ≠ cheap query.”

5️⃣ Cost Control Mechanisms

Tool Purpose
Partitioning Reduce scanned data
Clustering Speed up filters
Max bytes billed Prevent runaway queries
Billing export Analyze spend

🧠 Design tables to control cost.

6️⃣ Security & Access

IAM (two permissions needed)

To run a query, users need:

  1. Job permission (run queries)
  2. Data permission (read tables)

Common roles:

  • BigQuery Job User
  • BigQuery Data Viewer

🧠 Rule:

Query = job permission + data permission.

Views (very testable)

  • Expose derived data
  • Hide raw tables
  • Use for data security

🧠 Secure data access with views, not table permissions.

7️⃣ Operations & Limits

  • Query quotas
  • Max bytes billed
  • No server management
  • Automatic scaling

🧠 BigQuery scales automatically — cost is your responsibility.

🔑 BigQuery — Exam-Safe One-Liners

  • “Large analytics queries” → BigQuery
  • “Reduce query cost” → Partitioning
  • “Prevent expensive queries” → Max bytes billed
  • “Secure aggregated access” → Views
  • “Data location matters” → Dataset location

If you can map a question to one of these, you’ll answer correctly.
